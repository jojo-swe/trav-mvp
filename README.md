# trav-mvp

Privat MVP för prediktion av svensk trav **V75** / **V85** utifrån officiell data (ATG / Svensk Travsport), inkl. robotinformation där det finns.

## Status

WIP — datakällor och modell byggs ut. Mapp `data/` innehåller hämtade officiella JSON-exempel.
